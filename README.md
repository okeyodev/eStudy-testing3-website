# StudyPod (eStudy)

StudyPod is a responsive landing page for an online learning platform that connects learners with tutors, live classes, and recorded lessons.

**[Visit the live site](https://okeyodev.github.io/eStudy-testing3-website)**

## Preview

![StudyPod website preview](Screenshot.png)

## Features

- Browse tutor profiles and filter tutors by subject.
- Preview tutor videos and explore recorded learning content.
- Find information about webinars, the learning library, and pricing.
- Switch between light and dark themes.
- Use the responsive navigation on mobile and desktop.
- Explore FAQs, testimonials, and newsletter sign-up sections.

## Built with

- HTML
- CSS
- JavaScript

The page also loads the Inter font from Google Fonts and uses externally hosted images.

## Run locally

No build step or package installation is required. From this directory, start a local static server:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.
